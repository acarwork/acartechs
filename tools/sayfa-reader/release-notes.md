# Sayfa Kitap Okuyucu 1.0.1

A Windows x64 desktop reader from AcarTechs. This release installs per user and adds Start menu and optional desktop shortcuts.

## Installation

- Run `Sayfa-Kitap-Okuyucu-1.0.1-Windows-x64-Kurulum.exe` to install per user. The setup wizard can create a desktop shortcut and adds a Start menu shortcut. It can be uninstalled from Windows Settings.
- The setup wizard can be removed later from Windows Settings > Apps.

Library cards now have a three-dot menu to open, mark as finished, or remove a book. PDF rendering cancels outdated draws and limits oversized canvas memory use.

## Included in this release

- PDF reader with page navigation, page fit, zoom controls, text selection, bookmarks, notes, highlights, and full-screen mode.
- EPUB reader with saved reading location, configurable font size and line spacing, notes, bookmarks, highlights, and speech synthesis.
- TXT, HTML/XHTML, FB2, and CBZ reading.
- Local library records, progress, notes, and bookmarks stored on this computer.
- PDF.js 3.11.174, EPUB.js 0.3.93, and JSZip 3.10.1 are bundled locally.

## Current limits

- MOBI, AZW, AZW3, and CBR files cannot be read in this release.
- Scanned PDFs do not include OCR. PDF text-to-speech and text selection require an extractable text layer.
- Cloud sync, PDF page rotation, two-page spread, and whole-book search are not included in this first phase.
- These EXE files are not code-signed; Windows SmartScreen may show a warning.
